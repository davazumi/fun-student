# fun-student

REST API на Spring Boot 4 для учёта студентов и пользователей с JWT-авторизацией.

## Тесты

- JUnit 5 + Mockito: сервисы, мапперы, JwtService, обработчик ошибок.
- Интеграционный тест StudentControllerIntegrationTest: вход по JWT (admin / teacher), получение списка и студента по id, создание студента, ответы 404, запрос без токена и с испорченным токеном.
- Для тестов используется встроенная БД H2 — PostgreSQL не нужен.
